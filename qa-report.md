## 📋 Общие проблемы

### Визуальные

1. **Неправильная навигация (P0)**
   - Во всех страницах (65,221 HTML-файлов) опечатка "Каталог" → "Катalog"
   - Косметическая проблема, но раздражает пользователей
   - Позиции: index.html (строки 29, 38), news/index.html (строки 29, 38), catalog/*.html (все файлы)

2. **Отсутствующие изображения карточек новостей (P1)**
   - На странице news/index.html карточки новостей содержат пустые ссылки на изображения
   - Это нарушает визуальную целостность карточек

3. **Очень длинные названия товаров (P2)**
   - Некоторые названия товаров содержат до 200+ символов
   - Могут вызывать проблемы с отображением на мобильных устройствах

### Логические

1. **Отсутствие корзины (P0)**
   - Корзина доступна через навигацию и кнопки, но страницы нет
   - Это критическая проблема для e-commerce портала
   - Рекомендуется создать хотя бы заглушку с инструкцией

2. **Отсутствие страницы заказа (P0)**
   - Ссылка "Быстрый заказ по артикулу" ведет в пустую папку
   - Неизвестно, какой функционал должен быть реализован

3. **Отсутствие страницы поиска (P0)**
   - Кнопка "Найти" в поисковых формах ведёт в пустую папку
   - Модуль поиска должен быть реализован

4. **Отсутствие карты дистрибьюторов (P0)**
   - Есть 37 локаций дистрибьюторов в data/distributors.json
   - Карта нужна для визуализации сети продаж
   - Уже есть папка leaflet в assets/

5. **Неполная информация о ценах (P1)**
   - Цены не отображаются на карточках товаров
   - Только текст "цена у дистрибьютора"
   - Это существенно ограничивает юзабилити

6. **Статус "под заказ" без сроков (P1)**
   - 135 товаров показывают статус "под заказ"
   - Нет информации о сроках поставки
   - Пользователи не могут оценить доступность товаров

### Данные

1. **Плейсхолдеры в контактных данных (P1)**
   - Телефон: +375 (00) 000-00-00 - явно не реальные данные
   - Email: info@иэк.бел - возможен, но нужно проверить существование

2. **Неверная статистика (P1)**
   - Количество позиций: 76156+ - нет источника данных для этой цифры
   - Количество точек дистрибьюторов: 37 - противоречит data/distributors.json (16 дистрибьюторов, 37 локаций)
   - Рекомендуется проверить актуальность данных

3. **Пустые каталоги (P0)**
   - catalog.json: только 13 продуктов в примере
   - Real каталог должен содержать 76,156+ позиций (как заявлено на сайте)

4. **Отсутствие контактов для локаций (P2)**
   - Некоторые локации дистрибьюторов не имеют телефонов
   - Формат: `"phone": null`

5. **Проверка статуса дистрибьюторов**
   - 4 подтверждённых, 4 неподтверждённых, 3 заявленных, 1 без статуса
   - Необходимо проверить актуальность статусов в data/distributors.json
