# Исследование корпоративных ресурсов ИЭК (iek.ru + bp.iek.ru)

Дата: 05.11.2026. Изучены: официальный сайт, каталог (Next.js SPA), бизнес-платформа
(личный кабинет партнёра), публичный API клиентов. Цель — взять архитектурные
паттерны для портала иэк.бел.

---

## 1. iek.ru — официальный сайт

### Технологии
- Основной сайт: Bitrix (`/local/templates/…`), каталог продукции — отдельное **Next.js SPA** (`/products/catalog/_next/…`)
- CDN медиа: `cdn-01.iek.ru`
- Важно для нас: URL без завершающего слэша в SPA отдают 404 → строгая нормализация URL

### Структура каталога (таксономия с номерами)
19 направлений с числовой нумерацией: 01. Модульное оборудование, 02. Силовое
оборудование защиты и коммутации, 03. Приборы учёта…, 04. Щитовое, 05. Системы
для прокладки кабеля, 06. Электроустановочные, 07. Коммутационное, 08. Электромонтажные
и инструменты, 09. Элементы питания, 10. Светотехника, 15. Проектная светотехника
LEDEL/FEREKS, 17. Металлоконструкции, 20. Телеком, 21. ПО, 30. Автоматизация,
40. Шинопровод, 41. Продукция Контактор, 43. АСИП/муфты, 61. LEGRAND (лимитированный).

Внутри направления — **платформы**: 01.01 ARMAT, 01.02 MASTER, 01.03 UNION, 01.04 KARAT, 01.05 Другие серии.

### URL-паттерны (глубина до 6 уровней!)
```
/products/catalog/<группа>/<платформа>/<тип>/<серия>/<модификация>/<товар>
пример: /products/catalog/modulnoe_oborudovanie/modulnoe_oborudovanie_karat/
        modulnye_avtomaticheskie_vyklyuchateli_karat/
        modulnye_avtomaticheskie_vyklyuchateli_va47_29/
        modulnye_avtomaticheskie_vyklyuchateli_va47_29_khar_ka_c/
        karat_avtomaticheskiy_vyklyuchatel_va47_29_1p_c_6a_4_5ka_iek
```
- Слаги: латиница + `_`, кодировка ETIM для типов (`?classId=EC000042`)
- Хлебные крошки с номерами: Главная › 01 › 01.04 › 01.04.01 › 01.04.01.01 › 01.04.01.01.02

### Карточка товара (что повторяем на иэк.бел)
1. H1 по конвенции: **«KARAT Автоматический выключатель ВА47-29 1P C 6А 4,5кА IEK»**
   (= платформа + тип + серия + полюса + хар-ка + ток + отключающая способность + бренд)
2. Артикул с копированием + генератор QR-кода
3. Галерея ~10 фото + видео
4. «Основные характеристики» — таблица из 5 ключевых параметров + «Посмотреть все»
5. Кнопка **«Купить»** → маршрут к покупке (BP/дистрибьюторы)
6. Вкладки: Описание | Характеристики | Документация | BIM&CAD, конфигураторы | Логистические параметры | Отзывы
7. Описание + «Срок службы: 15 лет», «Гарантия: 10 лет»
8. Документы (схемы подключения, руководства) с CDN

### Шапка сайта
Тёмный графит, крупный лого с теглайном «ВКЛЮЧАЕМ В ЖИЗНИ», жёлтая кнопка
«Каталог», поиск prominent, меню: Где купить | Каталоги | **Прайс-лист** | Гарантия | Контакты.
Второе меню: Компания, Решения, Промо, Бренды, Поддержка, Инвесторам, Обучение (univer.iek.group), Новости.
SSO-вход «Войти с IEK ID».

### Прочее
- Публичный прайс-лист: /products/price/ (+ xlsm по светотехнике)
- «Где купить»: /products/where_to_buy/
- Сравнение и Избранное — в каталоге
- Фильтры каталога: семейство, серия, тип продукции (ETIM), параметры

## 2. bp.iek.ru — бизнес-платформа (кабинет партнёра)

### Вход
- /auth/phone (по умолчанию, код по SMS) / /auth/password (email+пароль, кнопка «Войти с паролем»)
- SSO IEK ID с основного сайта

### Что внутри (главная /home)
- **Статусная линейка**: VIP скидка 47%, прогресс «До сохранения статуса: X ₽» (оборот за год)
- Программа лояльности **IEK PROFI**: баллы за задания → мерч
- Разделы: Каталог | Мои проекты | IEK Univer (/sdo) | Инструменты для E-com | Печатные каталоги | Каталог новинок | Коммерческие предложения
- Акции (кэшбэк у партнёров, «Русский Свет» и др.), Мероприятия (семинары ЭТМ и др.)

### Каталог BP (/catalog)
- Таксономия = iek.ru + доп. бренды: **UNION** (01.03), ТМ **GENERICA** (60.xx), Профэско
- Фильтры: цена (мин/макс), «Честный знак» (маркировка), «Доступно к покупке», «Участвуют в акции», «Только в наличии», серии
- Сортировка «По убыванию скидки»
- «Скачать прайс-лист» на любом уровне

### Карточка товара BP — модель ценообразования (ключевое!)
```
В наличии: 945 шт          Артикул: MVA20-1-025-B

БАЗОВАЯ ЦЕНА            351,86 ₽
РРЦ  (розница)          263,90 ₽   Ваша наценка +42%
РОЦ  (опт)              225,19 ₽   Ваша наценка +21%
ВАША ЦЕНА (закуп)       186,49 ₽   Ваша скидка  −47%
```
- «Добавление в спецификацию» с количеством — **заказы собираются в спецификации** (BOM), не в корзину
- Вкладки: Описание | Характеристики | Документация | BIM модели | Параметры логистики | Похожие товары
- Спецификации: /specification — список с суммами, активная + архивные, «Создать спецификацию»

### Вывод для иэк.бел
Ценовая модель BP (База/РРЦ/РОЦ/Ваша) — это то, что портал должен показывать
дистрибьюторам; в публичной части иэк.бел показываем «цену у дистрибьюторов»
без раскрытия маржи.

## 3. Публичный API клиентов (самое важное)

Документация: **https://bp.iek.ru/docs/client** (Redocly), версия 1.4.638
OpenAPI-спека: `https://bp.iek.ru/docs/content/api-doc/bp-client-api/openapi-new.json?version=3`
(сохранена: `_downloads/bp-api-openapi.json`)
Контакт: platform@iek.ru

### Аутентификация
```
POST https://bp.iek.ru/oauth/login
Content-Type: application/x-www-form-urlencoded
username=ticket & password=<API-ключ>
→ куки kc-access, kc-state
```
API-ключ выпускается в профиле: **/profile#api-keys** (показывается один раз).

### Эндпоинты (все данные для портала!)
| Метод | Путь | Что даёт |
|---|---|---|
| GET | /api/catalog/v1/client/catalog | Категории 1-го уровня |
| GET | /api/catalog/v1/client/category/{slug}/json | Все товары категории (JSON) |
| GET | /api/catalog/v1/client/category/{slug}/balances-json | **Остатки и цены** категории |
| GET | /api/catalog/v1/new-products | Новинки |
| GET | /api/catalog/v1/client/products/{article} | Карточка товара по артикулу |
| POST | /api/catalog/v1/client/analog | Подбор аналогов (массив артикулов) |

Формат JSON, авторизация по кукам после /oauth/login.

### Значение для иэк.бел
Полный конвейер: категории → товары → остатки/цены → карточки → аналоги.
Это закрывает Этап 2 дорожной карты («полный каталог из прайса») без ручного
ввода: nightly-скрипт тянет balances-json по всем категориям и пересобирает статику.

## 3а. API личного кабинета партнёра (lk.iek.ru, платформа Анкрон)

Документация в ЛК: «Обмен данными». Авторизация — **Basic** (логин/пароль API из ЛК,
хранятся в `.env`, файл закрыт `.gitignore`). Креды выдал представительство.

### Сервисы
| Сервис | URL | Что даёт |
|---|---|---|
| products | /api/products | **Все товары ГК IEK (75 453 SKU)**: name, price (базовая, ₽), saleprice, vat, roc, rrc + сущности по `entity=` |
| ddp | /api/ddp | Дерево каталога ДДП: 510 групп (section/kind/group/groupId) |
| residues | /api/residues/json/ | Остатки по складам (75 453 SKU; по SKU фильтр `?sku=`) |
| planresidues | /api/planresidues/json/ | План приходов на склады (даты + количества) |
| etim | /api/etim | ETIM-характеристики всех товаров |
| services | /api/services | Сервисные центры |
| seriesspecifications | /api/seriesspecifications | Спецификации серий (xlsx) |

### Ключевые параметры products
- Пагинация: `page`, `pageSize` (≤500); без groupId → dict с totalElements, с groupId → массив
- Фильтры: `groupId=01.01.02`, `TM=IEK|ITK|ONI|GENERICA`, `art=`, `updatedAtFrom=`
- Сущности `entity=`: Description (ru/en/es), Advantages, ImgPng/ImgJpeg, LeftPeriod
  (гарантия/срок службы), Analog, Certificates, LogisticParameters, rrc, roc, min_ship,
  order_multiplicity, ChestnyZnak* и ещё ~30 (полный список в доке ЛК)
- Файлы (изображения/документы) отдаются через `lk.iek.ru/api/store/...` — **требуют Basic-авторизацию**,
  поэтому для статического сайта их нужно скачивать на этапе импорта (в MVP не качаем)

### Проверено на практике
- Дерево ДДП: 510 групп; «Модульное оборудование» = 15 групп
- Импорт направления «Модульное оборудование»: **3 608 товаров** (ARMAT 1426, MASTER 580,
  KARAT 1280, другие серии 322)
- Остатки: 52,6 МБ выгрузка, 21 629 SKU с ненулевым наличием (склады Щ/БЛБ/Кув/Я)
- Курс НБРБ для пересчёта РРЦ в BYN: `api.nbrb.by/exrates/rates?periodicity=0` → RUB id=456, scale=100

### Реализовано: tools/import_lk.py
`python3 -I tools/import_lk.py --kind "Модульное оборудование"` → `data/lk-catalog.json`
(схема build.py + price{base,roc,rrc,rrc_byn,stock_total,stock_stores}). Сайт собирается
командой `python3 -I tools/build.py data/lk-catalog.json data/distributors.json site`.
Таким же образом импортируется любое направление (Светотехника, Щитовое и т.д.) или все сразу.

## 4. Что применяем к иэк.бел (применено/в плане)

Применено сразу:
- Официальный SVG-логотип, крупный, фирменные цвета/шрифты по логобуку
- SKU в формате ИЭК через дефис: MVA20-1-006-C (не MVA20-1-006C)
- Серия переименована в ВА47-29 (KARAT) — актуальное имя линейки
- Нейминг карточек по конвенции ИЭК: «KARAT Автоматический выключатель ВА47-29 1P C 6А 4,5кА IEK»

План (Этап 2):
- Импорт каталога через API: nightly-джоба → category/json + balances-json → catalog.json → rebuild
- В карточке: блок «Цена и наличие у дистрибьюторов» по модели BP (без маржи)
- Фильтры по ETIM classId, «Честный знак», «Только в наличии»
- Хлебные крошки с номерами направлений (01 → 01.04 → …)
- Подбор аналогов через POST /analog («нет позиции — подберём аналог»)

## 6. Партнёрская сеть РБ: данные и карта

- Данные: `data/distributors.json` — 16 компаний из списка представительства; по каждой
  юрлицо/УНП, сайт, специализация, статусы IEK (confirmed/declared/unconfirmed/none),
  locations[] с типами точек (офис/склад/магазин/пункт выдачи/производство), телефонами
  и координатами (Nominatim, approx=true — приблизительно)
- Страница: `/distributors/` (чипы статусов, типы точек, ссылки на Яндекс.Карты по каждой точке)
- Карта: `/distributors/map/` — **Яндекс.Карты** (виджет без API-ключа, маркеры цветом
  по типу точки, легенда). Апгрейд при росте трафика: Yandex MapKit JS + бесплатный
  ключ (убирает рекламную полосу виджета, даёт кастомные балуны)
- Локальное SEO: на обеих страницах JSON-LD LocalBusiness по каждой точке (адрес, geo,
  телефон) — под запросы «иэк + купить + город»
- Верификация: агенты посещают сайты компаний (контакты/магазины/где купить), различают
  юр.адрес ≠ фактический адрес ≠ склад ≠ магазины; статусы подтверждены страницами
  брендов IEK на сайтах компаний. Список и статусы финально сверяет представительство

## 7. Безопасность
- Пароль BP передавался в чате открытым текстом → после настройки доступа
  рекомендуется сменить пароль и выпустить отдельный API-ключ для портала
- Ключ API хранить в переменных окружения, не в репозитории
