# иэк.бел — видение продукта (v1, 11.11.2026)

## Суть
Публичный портал представительства ПАО «ИЭК ХОЛДИНГ» в РБ: каталог всей продукции
ГК IEK с честными характеристиками и наличие у официальных дистрибьюторов.
**Представительство не ведёт коммерческой деятельности в РБ** — покупка только у
официальных дистрибьюторов/реселлеров. Дисклеймер — в футере и карточке.

## Клиенты (все сегменты РБ)
От частника-электрика до снабженца предприятия; сборщики щитов, перекупы,
КАМы маркетплейсов, DIY-сети. Разные цели — разный путь, но единая точка входа.

## Цель визита
Найти товар → увидеть честные характеристики/наличие → отправить заказ/запрос
официальному дистрибьютору (одному или всем).

## Карточка товара — обязательный состав (решено)
1. Фото в разных ракурсах (галерея)
2. Название + артикул с копированием
3. Наличие у дистрибьюторов (если нет API/данных — блок скрыт)
4. Наличие на складах ИЭК (+ план приходов)
5. Характеристики: основные (6 шт. как на BP) + все (ETIM)
6. Описание, Преимущества
7. Комплектность
8. Гарантия, Срок службы (плитки с подписями)
9. Документы, паспорта, руководства
10. «С этим часто покупают»
11. Дисклеймер представительства

## Killer-фича
**Параметрический подбор из карточки** (как на avs.by): клик по «25А» → переход
на 25-амперный аналог той же серии. Источник — ETIM-характеристики соседей
по группе ДДП.

## Стиль
Брендбук ИЭК + модель BP: жёлтый/графит, TT Norms Pro + Druk, карточки-поверхности.

## Этапы
1. ✅ MVP-статика (3608 SKU модульного)
2. 🔄 Полный импорт 76k (выполнен) + ETIM (61k записей → SQLite)
3. Параметрический переключатель в карточке
4. Django: рендер из БД + админка заказов
5. API фиды дистрибьюторов → цены/наличие у каждого дистра
6. Деплой (VPS + Cloudflare) + SEO
