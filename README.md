# иэк.бел — портал заказа продукции ИЭК в Беларуси

MVP собран: статический сайт-каталог с маршрутизацией заказов к дистрибьюторам.
Готов к публикации на бесплатном хостинге (Cloudflare Pages).

## Фирменный стиль

## Запуск с нуля на любом устройстве (PyCharm)

1. Clone: `git clone git@github.com:stepkovich/iekbel.git`
2. Открыть проект в PyCharm → выбрать интерпретатор (любой Python 3.11+)
3. В Run-дропдауне уже лежит **«иэк.бел — запуск всего»** (приезжает из гита) → ▶️

`run.py` сам: создаст .venv с Django/Pillow (если надо), скачает каталог из API ИЭК
(нужен `.env` в корне — один раз на устройство), соберёт сайт, поднимет :8090 и :8091,
откроет браузер. Останов — красный квадрат.

Быстрое точечное обновление одной группы:
    python -I tools/build.py data/lk-catalog.json data/distributors.json site --cats <slug>



Сайт оформлен по брендбуку ИЭК (скачан с iek.ru/company/brandbook, оригиналы в `_downloads/`):
- **Цвета**: жёлтый `#F6E200` + графитовый `#1D252D` (основа); кирпичный `#FF4811` (цены), серые `#606567/#A1A5A7/#D6D6D6`
- **Шрифты**: Druk Text Wide Cyr Super (заголовок hero, капс) + TT Norms Pro Regular/Medium/Bold (весь текст) — woff2/otf в `site/assets/fonts/`
- **Логотип**: `site/assets/logo-iek.png` (RGBA, оригинал из брендбука); на обложке hero — жёлтый квадрат как отсылка к «точке» логотипа
- Правила соблюдены: без теней/градиентов/деформации лого, только фирменные цвета, контрастные фоны

## Архитектура: статика + динамический слой

```
Cloudflare Pages (site/)          Cloudflare Worker (tools/worker/)
├─ каталог 3 600+ SKU             ├─ /img/{SKU}.jpg   → фото из lk.iek.ru (кэш 1 год)
├─ описания, РРЦ, SEO-разметка    └─ /api/stock       → живые остатки: ИЭК + фиды
└─ live.js: бейджи → /api/stock      дистрибьюторов (кэш 10 мин)
```

- Ключи API только на сервере (в воркере), в браузер не попадают
- Без воркера сайт полностью работает на статических фолбэках
- Формат партнёрских фидов и деплой — `tools/worker/README.md`

## Пересборка после правки данных

```bash
# вариант 1: ручные данные (MVP-макет)
python3 tools/build.py data/catalog.json data/distributors.json site

# вариант 2: РЕАЛЬНЫЙ КАТАЛОГ ИЭК из API личного кабинета (сейчас используется)
python3 -I tools/import_lk.py --kind "Модульное оборудование"   # выгрузка из lk.iek.ru
python3 -I tools/build.py data/lk-catalog.json data/distributors.json site
```

Креды API — в `.env` (LK_API_LOGIN / LK_API_PASSWORD, закрыт .gitignore).
`--kind` — любое направление ДДП («Светотехника», «Щитовое оборудование», …).
Ручной слаг-патч категорий после импорта больше не нужен (slugify транслитерирует русский).

## Чек-лист запуска (по порядку)

### 2. Хостинг (бесплатно)
- [ ] Аккаунт Cloudflare → Pages → загрузить папку `site/` (drag&drop)
- [ ] Привязать домен: в hb.by указать NS Cloudflare; домен вводить punycode'ом `xn--h1ae0d.xn--90ais`
- [ ] SSL включится автоматически

Альтернатива: hb.by Unix Старт (5,40 BYN/мес) — если позже понадобится серверный код.

### 3. Юридическое
- [ ] Регистрация сайта в **БелГИЭ** (обязательно для сайта, представляющего услуги в РБ)
- [ ] Письмо/согласование от ПАО «ИЭК ХОЛДИНГ» на использование товарного знака и домена (для реестра и спокойной жизни)
- [ ] Политика обработки персональных данных (форма заявки собирает ПДн — Закон № 99-З)

### 4. SEO-пусконаладка
- [ ] Яндекс.Вебмастер: добавить сайт, отправить sitemap.xml
- [ ] Google Search Console: то же самое
- [ ] Яндекс Бизнес + Google Business Profile: карточка представительства

  - дистрибьюторов в `data/distributors.json`

### 5. Контент-план SEO (очередь статей)

3. «Где купить оригинальную продукцию ИЭК в Беларуси» — коммерческий якорь
4. «Подделки ИЭК: как отличить оригинал» — E-E-A-T, доверие
5. Далее по 2–4 статьи/мес + карточки товаров (расширять `catalog.json`)

## Дорожная карта

| Этап | Что | Когда |
|---|---|---|
| MVP (текущий) | Каталог + заявки дистрибьюторам | готов |
| Этап 2 | Полный каталог (импорт из прайса ИЭК), поиск по сайту | +1 мес |
| Этап 3 | Кабинеты дистрибьюторов: обработка заявок, остатки | +2–3 мес |
| Этап 4 | Личные кабинеты покупателей, история заказов, спеццены | по мере роста |

## Технические заметки
- Домен кириллический: во всех внешних системах (DNS, Cloudflare, Вебмастер) используется punycode `xn--h1ae0d.xn--90ais`
- Форма заявок сейчас шлёт через formsubmit.co (бесплатно, без бэкенда); на Этапе 3 заменить на API кабинетов
- Sitemap обновляется автоматически при каждой пересборке
